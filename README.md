# Place of Grace Community Centre Website

A modern, responsive website for Place of Grace Community Centre - providing love, care, and hope for vulnerable children.

## 🌟 Features

- **Modern UI/UX**: Beautiful animations and smooth transitions
- **Multi-language Support**: English and Kiswahili
- **Responsive Design**: Works perfectly on all devices
- **Interactive Elements**: Smooth scrolling and polished button animations
- **Search Functionality**: Real-time website search
- **Animated Backgrounds**: Unique animations for each page
- **Accessibility**: Full accessibility support with proper focus states

## 🚀 Live Website

Visit: [www.placeofgracecommunitycentre.org](https://www.placeofgracecommunitycentre.org)

## 🛠️ Technology Stack

- **React 18** - Modern React with hooks
- **React Router** - Client-side routing
- **CSS3** - Modern styling with animations
- **GitHub Pages** - Hosting and deployment
- **GitHub Actions** - Automated deployment

## 📁 Project Structure

```
src/
├── components/          # Reusable React components
├── pages/              # Page components
├── styles/             # Global styles and themes
├── utils/              # Utility functions
├── contexts/           # React contexts
└── assets/             # Images and media files
```

## 🚀 Deployment

This website is automatically deployed to GitHub Pages using GitHub Actions. Every push to the `main` branch triggers an automatic build and deployment.

### Manual Deployment

If you need to deploy manually:

1. **Build the project**:
   ```bash
   npm run build
   ```

2. **Deploy to GitHub Pages**:
   ```bash
   npm run deploy
   ```

## 🔧 Development

### Prerequisites

- Node.js 18 or higher
- npm or yarn

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/SirByrone/Updated-Place-of-grace.git
   cd Updated-Place-of-grace
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm start
   ```

4. **Open in browser**:
   Navigate to `http://localhost:3000`
